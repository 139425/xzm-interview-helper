# 观市 · 股票学习实验室

以 A 股为主的可视化学习、交易练习与消息阅读工具。打开后即可学习，不需要填写 API Key。真实行情和虚构模拟明确分区。

## 你可以做什么

- **学习地图**：15 个单元、原创类比、深入追问、具体算账案例、现实核对问题、30 道情境题；保存进度与收藏。
- **交互实验**：改变股权、撮合、OHLC、财报、现金流、估值、除权、复利、回撤、仓位、相关性、预期、成本和 ETF 费用的参数，立即查看数值与图形。
- **模拟市场**：5 个虚构标的，5 种可重现场景；K 线、成交量、交易标记、T+1、100 股买入、10% 范围、佣金、最低佣金、滑点、印花税与过户费；条件挂单、冻结、撤销和最多250个交易日推进。
- **市场解读**：6 个真实观察标的、120 日公开日 K、原始报价时间；官方消息的事实、解读与追问，以及按主题生成的新消息阅读提示。
- **复盘**：含费用的持仓成本、已实现/未实现盈亏、净值、场景基准、回撤、费用归因、交易理由、笔记与导出。

建议先学股权、撮合与 K 线，再用 100 股做一次买入，推进一天后卖出，回到复盘检查钱去了哪里。

## 在本文件夹启动

外层 `启动观市.command` 可在当前 Mac 上双击。它优先使用 Codex 已有的 Node 运行时，也支持系统 Node。地址为 `http://127.0.0.1:5173/`；关闭终端即可停止。

独立环境需要 Node.js 22.13+（推荐当前 LTS）和 npm：

```sh
npm ci
npm run build
# 仅全新、本地数据库首次初始化时执行一次；已有数据时不要重放。
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_sharp_wallflower.sql
npm run dev
```

本地 D1 保存在 `.wrangler/state`，默认身份保存在 HttpOnly 浏览器 Cookie 中。删除 Cookie 会切换到新空间，旧记录仍留在数据库。私人发布按平台登录身份区分空间。浏览器 localStorage 不保存账户资金或交易记录。

## 数据与模型边界

- 规则核验日期：2026-10-02；2026版沪深规则于7月6日起施行。详细条文和一手来源见 [交易规则研究](docs/market-rules.md)。
- 模拟只有普通主板规则的教学子集。公司与价格路径虚构；条件委托由模拟器逐日重申报，并非交易所永久跨日申报。日 K 撮合不还原逐笔盘口。单笔不得超过当日成交量1%；不足时整笔等待，不做部分成交。
- 2026假日日历已核验。未来年份仅排除周末和固定法定假日，其余为预估，并在界面标注。
- 行情与日 K 来自腾讯公开接口，延时和服务保障未知。个股日 K 成交量按源口径“手”显示；指数使用明确的指数源口径。失败时保留原始时间的旧快照，不生成替代的真实价格。
- 官方消息在页面开启时每10分钟检查，可手动刷新；属于站内未读提醒。关闭页面后没有后台通知任务。新标题仅生成主题阅读提示；已核验条目才标“已核验解读”。
- 佣金已含经手与监管费用。滑点在成交价中体现，不能在净收益里再次扣减。
- JSON 导出供归档；当前版本没有导入恢复界面。交易 CSV 可直接用表格软件打开。

## 结构

`components/workspace.tsx` 组织学习、实验、消息与复盘；`components/simulator.tsx` 是交易终端；`components/charts.tsx` 提供可键盘查看数值的 SVG 图表。`lib/simulator.ts` 为纯函数交易引擎；`lib/experiments.ts` 为公式模型；`lib/market.ts` 为带缓存与失败回退的真实数据服务；`app/api` 负责持久化及版本检查。课程与研究来源位于 `lib/curriculum.json`、`lib/market-research.json` 和 `docs`。

使用 React 19、TypeScript、vinext/Vite、Cloudflare Worker 与 D1。源代码位于这个文件夹内；依赖、构建产物、本地数据库均已被 Git 忽略。
