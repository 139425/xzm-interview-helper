# 观市 · 股票学习实验室

面试助手中的股票学习工具，入口为 **工具 → 学习工具 → 观市 · 股票学习**。主路径 `/tools/market-atlas/`。以 A 股为主，从个人预算、账户和开户流程开始，逐步学习市场、公司、风险和交易复盘。真实行情与虚构模拟分别呈现。

## 学习与练习

- **学习地图**：21 个单元、5 个阶段。每课有详细章节、可点击图解、分步案例、常见误区、实践清单、术语和标有适用范围及核验日期的一手资料。
- **情境测验**：132 题，覆盖入门、应用和判断；提交后逐项解释选项，保存成绩。旧版本的两题结果保留原分母，扩充题库可重新练习。
- **交互实验**：原有 15 种公式模型全部保留；21 个单元均有可调实验，另有双滑杆的 20 日日均资产图解。先预测，再调整变量；数值均为教学假设。
- **模拟市场**：5 个虚构标的、8 种可重现场景，涵盖跳空、低流动性与停复牌。五档即时委托、DAY 限价委托、跨日条件、部分成交、冻结与撤销、价格时间优先、T+1、费用和日级行情。
- **真实市场与复盘**：原始日期报价、公开历史日 K 和官方消息阅读；账户净值、基准、回撤、费用、交易理由、笔记、JSON 备份与 CSV 导出。

建议先按“新手起步”读完账户、权限与操作流程，再在模拟器完成买入、观察冻结、下一交易日卖出和账本复盘。页面只讲解开户流程，不收集证件或办理金融账户。

## 本地运行

需要 Node.js 22.13+。在本目录运行：

```sh
npm ci
npm run build
npm run start:server
```

首次启动自动创建缺失的表，不清空已有数据库。默认访问 `http://127.0.0.1:5174/tools/market-atlas/`；面试助手前端开发代理也保留此路径。开发热更新用 `npm run dev -- --port 5174`，全新开发数据库按 [集成说明](docs/integration.md) 初始化。

学习记录保存在 D1。没有可信平台登录身份时以 HttpOnly Cookie 区分空间；删除 Cookie 会打开新空间，旧数据仍留在数据库。浏览器 localStorage 不存资金或成交记录。

## 数据与模型范围

规则核验于 2026-10-02。沪深 2026 交易规则自 7 月 6 日施行；课程单独说明主板、创业板、科创板、北交所和基金差异。本模拟器使用普通主板的教学子集，不代替各板块的实际交易系统。

日 K 线不能还原盘中先后顺序；盘口和成交量是合成教学数据。每个标的、每个方向共用当日成交量 1% 的预算，拆单、撤单或反向交易不刷新。即时单余量撤销，DAY 单跨日失效；条件单由模拟器逐日重新申报。集合竞价、盘中价格笼子、融资融券、新股与企业权益事件等未完整模拟，界面展示这些范围。2026 假日日历已核验，未来年份额外假期为预估。

腾讯公开行情的延时和服务保障未知；失败时显示原始时间的旧快照。消息在页面开启时每 10 分钟检查，关闭页面没有后台通知。佣金以券商约定为准；模拟滑点已计入成交价，不重复扣款。

最多推进 250 个交易日、500 个委托、1000 笔成交。全学习空间 JSON 另有 200 万字符的保存限制，笔记共享该额度；达到限制时保留已有记录并提示导出，不截断历史。JSON 备份供归档，当前没有导入恢复界面。

## 运行与部署

使用 React 19、TypeScript、vinext/Vite、Cloudflare Worker 和 D1。`components/workspace.tsx` 整合页面，`components/lesson-reader.tsx` 提供详细课程阅读，`lib/curriculum.json` 保存课程，`lib/simulator.ts` 是纯函数模型。

服务器设置、持久目录和回滚流程见 [部署说明](deploy/README.md)。源码、研究与验证文档可进入 Git；依赖、编译产物、数据库、凭据和实际部署地址不进入 Git。
