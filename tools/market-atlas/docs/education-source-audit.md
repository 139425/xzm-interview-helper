# 课程内容与官方来源核验

本记录对应 `lib/curriculum.json` 的第二版课程。核验日期为 **2026-10-02**；它表示本次查阅时间，不表示规则永久有效、所有机构界面相同，或任何人的真实开户/交易资格已获确认。机构动态流程、特殊身份、具体证券状态与正式申请反馈须在实际办理时再次核验。

课程保留原 15 个 lesson id、原实验 kind/controls/formula 与原首两题的题干、选项和答案索引，新增 6 个“新手起步”单元。21 课按资金准备→账户/机构→开户适当性→委托→板块权限→权益保护→原概念课程排列。`guide` 承载详细正文、原创分步案例、误区、复习、词汇、图解和来源；测验补 `optionExplanations` 及难度。章节篇幅和题数是完整性检查，内容是否讲清机制及适用边界另由逐课阅读与独立对抗审查判断。

## 证据的使用边界

- 中国内地开户、准入、交易与税务使用监管部门、证券业协会、交易所、财政部、税务总局的官方资料。网址目录含年份不等于正文的发布或修订年份，优先检查正文、施行日、废止与过渡安排。
- SEC、Investor.gov 和 FINRA 仅支持股权、报表、配置、费用及行为等通用概念；美国账户、订单、税务和产品机制不作为 A 股制度依据。
- 咖啡店、餐馆、小林、虚构基金、资金预算、所有演算数字及题目均为原创教学情境。来源用于核对定义与制度点，不转载全文，也不复制来源中的长段文字或原例题。公式的独立算术结果不作为来源的市场预测。
- 简化实验只解释条件关系；课程明确模型未覆盖的事项。新手课复用已有实验时按 `experiment.kind` 选模型，图解日均资产交互与下方仓位实验分别承担不同问题。

## 两轮内容对抗审查与修正

第一轮在生成初稿时主动检查“看似新地址是否新规则”“数值是否万能门槛”“收益是否被写成保证”。排除了协会较新地址上的旧柜台开户条款，使用 2023 资金账户规则；排除通用 C3/固定分数；修正沪深风险警示旧 5%；补北交所科创板权限例外；注明中登全文获取缺口；把分红税前/净税负、配股本金及发布/施行日期分开。

第二轮由独立 `simulator_expansion` 只读审查，原稿逐条修正：

- `compound`：直接相加不是算术平均，改为相加后除期数，并明确累计乘积。
- `orderbook`、`beginner-first-order`：补普通当日申报收盘失效及条件功能以后重新提交，增加 200 股部分成交/余量对照案例。
- `beginner-opening`：改准确边界“70 周岁及以上”；增加账户开立但转入失败的状态排查。
- `beginner-accounts`：增加协会公司/分支查询直接入口与全称→名录→独立客服→入口实例。
- `etf`：补净值扣负债公式、110/10/50 万的演算，明确二级买卖与申赎不同以及回转规则需分品种。
- `equity`：增加终止上市公告卡，按类型、整理与停牌、权限/成交、摘牌后股份确认查阅。
- `candle`：原演算最低 8.9 相对昨收 10 超过普通主板 10% 范围，改为最低 9、跨度 0.8，避免新手误套常见主板制度；四价数学原本成立，问题在场景范围。
- `beginner-markets`：原日均练习不应指向仓位实验，改为本课独立日均图解，明确下方 `position` 是另一个问题。
- 深化后的复核继续修正：ETF 不套股票板块标签；买入跨越卖价档；小额往返改为多日而非误示普通 A 股 T+0；教学条件委托的余量持续冻结、次日重试和费用检查按实际模型表述。
- `beginner-accounts` 用 1,000 元持仓卖出扣 5 元费用→995 元资金的守恒例子，区分资产损失与可取延迟；`beginner-money` 的收入中断案例明确独立预算，避免复用前例资金造成双扣。
- `cashflow` 把经营、设备投资、借款融资和现金桥的新增段落重新与各节标题对应；餐券例改成已经履约的赊销，避免混入预收款/合同负债；多期段增加两季回款对照及旧款仍未收的反例。

主 Agent 另发现新手 id 被旧实验分派落入复盘分支产生 NaN，已将 UI 按 `experiment.kind` 分派并扩测。课程保留原实验数据合同，不靠修改公式掩盖集成问题。正文也从概念摘要深化为定义/机制、具体情境、核验与不成立条件，并补每课第二个完整案例；长度仅作遗漏检测，不能单独证明教学质量。
