# 淡蓝色学习地图设计审查

## 设计方向

沿用观市清晰的侧栏、学习路线、进度和大卡片结构，以「一本可以探索的市场地图」作为视觉线索。浅蓝侧栏、柔蓝继续学习卡和白色进度卡形成轻重层级；原创 SVG 路径连接四个节点，呼应从概念到判断的学习旅程。课程和计算内容没有因这次样式工作改写。

配色在全局基础规则和原模块声明中重整，不靠在文件尾叠加绿色换色补丁。主要文字为深蓝，正文采用 14–16px；数值保留等宽数字。金融图表的红涨绿跌与买卖语义继续保留。

## 官方设计基准

- [Awwwards 官方作品评分页](https://www.awwwards.com/sites/str8fire)公开列出 Design、Usability、Creativity、Content 及开发评审中的可访问性、响应式等维度。这里将它落实为排版层级、清晰下一步、原创地图图形、键盘反馈和窄屏适配。
- [Webby 官方评审标准](https://www.webbyawards.com/judging-criteria/)强调结构与导航、视觉设计、功能、交互和整体体验。阶段筛选使用原生按钮及 `aria-pressed`，卡片不裁掉问题描述，进度同时提供文字与进度条语义；动效用于反馈和短暂入场。
- [FWA 官方 25 周年页面](https://thefwa.com/FWA25/25.html)已取得正文，介绍其对数字设计与开发创新、创意、原创性和技术表现的关注。本次采用原创 SVG/CSS 学习旅程和教学图解，保留明确的数值、状态与交互语义。这是设计参照，不代表本项目获奖，也不将介绍文字编造成评分细则。

## 已修正的问题

1. 原样式大量正文和控制标签为 6–12px，窄屏还继续缩小。现统一清理到至少 12px，主要阅读正文为 16px，课程问题为 14px；移动课程单列显示。
2. 原绿色暗侧栏和细小、偏淡标签重整为浅蓝侧栏与更深文字。静态 WCAG 相对亮度核算：正文约 12.1:1、通用次级文字约 5.0:1、继续学习正文约 4.8:1、侧栏次级标签约 4.9:1。
3. 阶段元数据和 hero 小标签初稿的对比度不足 4.5:1，已加深；买卖标签与按钮也提高文字对比度。
4. 搜索、图例、分段控制、步进、数量加减和轻量文字按钮补足 44px 触控高度；主按钮为 46px。单选框排除全局输入框 padding，避免圆点尺寸被挤压。
5. 焦点采用清晰外轮廓。`prefers-reduced-motion` 禁用入场、位移和过渡；高对比模式为主要按钮和课程卡提供系统边框。
6. 课程总数、阶段数、每阶段数量、有效完成数和百分比均由 props 推导，不再将 15 个单元或四阶段写死在新组件中。

## 本次静态验证

PostCSS 成功解析完整样式；新增组件通过 TypeScript 检查。检查了 360/390、768、1440、1920 对应的 CSS 分支、列数和侧栏布局：900px 以下启用抽屉侧栏，600px 以下课程单列，宽屏课程与阶段采用五列；阶段列表与数量按课程数据推导，筛选后按可用宽度排列课程。

## 独立课程阅读器审查

核对日期：2026-10-02。范围为 `components/lesson-reader.tsx`、`components/lesson-reader.css` 与 `workspace.tsx` 的接入。独立审查仅读取源码、在内存执行交互状态驱动和计算图形比例；浏览器验收由主任务完成，没有将静态检查表述为实际浏览器或读屏测试。

1. **费用与资金比例**：费用条形图原先的示意宽度不能代表真实占比，已按 5.00/0.50/0.01 元及总费用 5.51 元改为约 90.74%/9.07%/0.18%，同步无障碍文字。股票 3 万、现金 7 万的例子核算为股票跌 30% 后账户 9.1 万、账户跌 9%、股票仓位约 23.08%；资金、证券份额与实时行情不混用。
2. **K 线与净值路径**：原 K 线例子昨收 10 元而最低 8.80 元，超出图中普通主板的 10% 下限。现开盘 9.10、最高 10.20、最低 9.00、收盘 9.50，影线和实体按同一价格尺度绘制；仍能解释「阳线但相对昨收下跌 5%」。净值 100/120/84/110 对应纵坐标 90/30/138/60，统一为每净值单位 3px，避免将 30% 回撤画小。
3. **保存竞态复现与修正**：用阅读器真实源码的内存转译和延迟 `onSave` 驱动，复现先提交正确答案、保存未返回时改为错项，随后界面误报改后成绩为「已保存」。现增加本地 `saving`，保存期间禁用题目和重试，并复制提交答案快照。独立复测 `resolved=true` 显示实际保存快照，`resolved=false` 保留选择、不展示成功或解析，两个分支均解除保存状态。
4. **旧成绩与跨课状态**：旧 2 题结果按 `previous.answers.length` 展示原分母，并提示当前题库扩充；本次新题仍全部初始未作答。`LessonView key={lesson.id}` 重建题目选择、图解步骤、自查勾选和术语筛选，避免跨课程串状态。21 课的图解标签与说明数量对应，自查清单没有重复任务。
5. **六个续读状态**：实际执行工作区的选择表达式，验证未使用的 version 1 旧 `equity` 默认档显示新手首课；version 2 已打开 `equity` 保留该课；零完成但已打开 `costs` 继续该课；旧档有收藏或测验时保留 `equity`；最近课程已完成时选择首个未完成课程。只改变入口显示，不为迁移重写旧学习记录。
6. **文字与教学图覆盖**：小字加深，费用条与背景对比约 3.62:1。ETF/分散图移除整块透明度，仅改变背景 HSL 明度；固定文字 `#174772` 在六块背景上的对比约 6.06–7.90:1。新增市场比较图，以 10/20/20/30 的相同基准绘出 33.33%/66.67%/66.67%/100% 长度，与课程列出的常规板块口径一致，并保留准入核验、新股等例外、不保证最大损失或跌停退出、ETF 不直接套用的说明。现在 21 课均包含概念图。

阅读器使用原生 `fieldset/legend`、单选框、复选框、`details/summary`、标签和来源链接；图解步骤有 `aria-pressed`，保存结果有 `role=status`。最终窄屏换行、焦点实际可见性、触控尺寸和读屏表现仍按下面的浏览器验收清单确认。
