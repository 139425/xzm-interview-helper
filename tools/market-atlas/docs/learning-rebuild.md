# 学习地图重做：验收依据

本次以用户 2026-10-03 的实际阅读反馈为准。上一版的字数、统一章节数和题目数不能证明教学质量。

## 已确认的问题

- 不知道股票是什么之前就谈账户、仓位、适当性和开户；先修知识倒置。
- 每课固定同一套流程，把故事、规则、公式都写成相同形状。
- 图解、正文、扩展阅读和案例反复解释相同内容，术语却没有在首次出现处解释。
- 完整教程像一张很长的清单，缺少读到这里具体会做什么的反馈。
- 核验脚本强制每节至少六段、每段至少250字，直接奖励冗长。

## 新的教学设计

四段路径：先懂股票与盈亏 → 走完第一次交易 → 看懂公司与基金 → 做出有依据的判断。

保持原课程 ID 和学习记录；正文重新写作。每课由按教学目的安排的内容块组成，允许故事、报价演示、账单、问答、流程、对照表、预测题、演算和研究任务交错出现。图在解释它的文字旁边，术语在第一次出现时解释。题目检验推理，不考作者的表述习惯。保留真实规则的适用范围和日期，但不把法律细节放在概念之前。

## 写作研究（2026-10-03）

- [Khan Academy：股票与债券](https://en.khanacademy.org/science/core-finance/stock-and-bonds)：从所有权到价格，再进入计算；吸收分步演示的方法。
- [Investor.gov：Stocks](https://www.investor.gov/introduction-investing/investing-basics/investment-products/stocks)：用读者会问的具体问题作标题，先给直接答案。美国交易规则不移植到A股。
- [Digital.gov：Design for understanding](https://digital.gov/guides/plain-language/design)：明确标题、短段落、适合比较时才使用表格，避免大片装饰性英文。
- [有知有行：钱是从哪儿来的](https://www.youzhiyouxing.cn/materials/182)：观察其从具体情境引出下一问题的叙事组织；不复制段落、历史论证或投资产品观点。

采用这些高层写法，原创人物、数字、案例和句子。信息密度以能完成实际任务衡量，不以段落长度衡量。

## 必须证明的结果

- 全部课程顺序符合先修关系，章节存在不同的叙述结构，早期课程不用未解释的金融术语。
- 每课有独立的教学目的、具体例子、过程说明、可检验的学习结果；题目与新正文吻合。
- 学习地图说明阶段目标与下一步；可折叠主导航、阅读专注模式、字号调节、进度与手机布局可实际使用。
- 问答助手使用 DeepSeek 4.1 非思考模式；检索当前版本的课程与官方来源；返回可点击的具体章节和建议；失联时明确失败，不把检索片段冒充AI回答。
- 模型密钥仅留服务端，不进入客户端包、Git或日志；有输入、并发、额度和超时边界。
- 对概念混淆、错误前提、越过先修课、无依据链接、提示注入、连续追问进行实际验收。
- 学习地图完成后审查实验、模拟市场、市场解读和复盘的语言、导航和边界。
- 本地构建、相称测试、真实浏览器验收、GitHub与服务器发布核验全部完成后才标记目标完成。

## 实际审查与修复

- 检索被金额数字带偏：过滤孤立数字词，给利润到账、存款与股权混淆补充概念映射，仍由模型结合课程回答。
- 第一轮真实回答把公司盈利简化成股东立即分成：补充分配条件。连续追问“只拿1万元分红”能接续持有10%的前文，算出税前1000元。
- 多轮历史用纯文本而模型处于JSON模式时出现空白输出：历史助手回答改为结构化JSON；空白输出重试一次，最终失败明确显示并保留问题。
- 科创板问题搭配创业板来源：段落绑定来源，合并同一文件的适用说明，单独询问科创板时排除创业板准入文件。已登记URL转成来源卡片，未知URL拒绝。
- 阳线被误当成个人盈利：分开开盘/收盘、昨收/今收、成本/现值三个比较。
- 同课段落跳转未滚动：每次导航触发定位，浏览器已验证关闭助手后定位到指定段落。
- 旧题提交可能污染新版分数：接口校验题库版本；旧测验首次覆盖前归档，新版阅读独立计数。
- 手机图标无名字、字号被媒体规则减小：补齐可访问名称，字号选择和实际大小一致。
- 首页图形卡片挤到下一行：调整标题区高度。
- 真实回答曾先说科创板资产“符合”，随后却算出日均仅2.5万元：增加独立的事实核对调用，重点检查结论、计算、必要条件与适用市场的一致性。核对失败返回明确错误，不展示未经核对的草稿。生成和核对均关闭思考模式。
