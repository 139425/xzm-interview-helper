「永久可用」如何保证?(多层容灾)
① Python 默认在你的浏览器本地执行(Pyodide/WebAssembly),首次加载缓存后不依赖任何服务器,断网也能跑;
② C++/Java 自动依次尝试多个免注册云端沙箱(Wandbox、Godbolt),任一存活即可运行,并动态解析编译器版本,避免硬编码过期;
③ 终极方案:自建开源 Piston 沙箱,一条命令:
docker run --privileged -dit -p 2000:2000 --name piston ghcr.io/engineer-man/piston
再用其 CLI 安装 gcc / java / python 运行时,然后在上方"自定义端点"填 http://localhost:2000/api/v2,即 100% 不依赖任何第三方;
